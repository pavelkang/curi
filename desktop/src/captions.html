Local captions

Pick a video or audio file (for example an OBS export). Curi Creator transcribes it locally with Whisper tiny — no cloud, no API key — and gives you WebVTT text. Then paste that text into the Edited captions field of the same lesson's video block in Studio. This window does not upload the file itself and does not replace Studio's Mux upload flow.

AI drafts — notes, chapters & quiz (DRAFT)

After transcription, generate draft lesson notes, timed chapters and quiz questions from the transcript — locally, no cloud. Edit them here, then copy the blocks into Studio as editable blocks. Nothing is published automatically and nothing is written to Supabase from this window. Drafts are labelled DRAFT: review the wording in Studio before the lesson goes to learners.

Paste a copied block into Studio as a new block of the same kind (markdown block, or quiz block), or paste the “all blocks” JSON as the lesson's content blocks. Check each question's answer and explanation in Studio — the drafts are cloze-style (fill-in-the-blank from the transcript) and weaker than LLM-drafted questions.
