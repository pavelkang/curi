Bundled Curi web app failed to start

This packaged build is supposed to run Studio from its bundled Next.js server (resources/curi-web/server.js), with no dev server needed. The bundle is missing or the server did not start, so Studio cannot be shown.

To rebuild the bundle and re-package:

cd ~/workspace/curi && npm run build
cd ~/workspace/curi-desktop && npm run bundle:web && npm run dist:linux

Or run Studio in dev mode instead:

cd ~/workspace/curi && npm run start -- -p 3100
cd ~/workspace/curi-desktop && npm start

See README.md in curi-desktop ("Packaged mode") for details.
