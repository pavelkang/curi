Packaged web app not bundled yet

This is a first-slice Electron shell. In packaged mode it does not yet bundle the Curi Next.js build, so it cannot show Studio from inside the installer.

To use Studio now, run it in dev mode instead:

cd ~/workspace/curi && npm run start -- -p 3100
cd ~/workspace/curi-desktop && npm start

Packaging the web build (Next.js standalone output or a bundled local server) into resources/curi-web/ is the next packaging slice. See README.md in curi-desktop.
